# Generated outputs

This directory is intentionally excluded from Git because outputs are reproducible,
can be large, contain machine-specific provenance paths, and may include
participant-level information.

Run notebooks in numeric order. Each notebook writes to its own named subtree and
creates tables, models, figures, logs, and manifests as applicable. See
`docs/ANALYSIS_GUIDE.md` for the exact mapping.

The three verified primary publication figures are collected under
`outputs/final_figures/` in PNG, editable SVG, and vector PDF formats for convenient
review. They are still generated artifacts and are never committed to Git.
